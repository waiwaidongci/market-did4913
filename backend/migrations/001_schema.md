# 001 初始表结构

应用首次启动以 SQLAlchemy 模型创建表与唯一约束。现有数据表只补建缺失表，升级到修改过字段的版本需要显式迁移。

- `users` 账号角色和加盐密码摘要。
- `datasets` 不可变记录批次，以名称和 SHA-256 去重。
- `runs` 记录参数、数据批次、运行租约、分析结果、导出文件及复核决定。
- `schedules` 保存定时计划和下一到期时间。
- `deliveries` 保存站内分发回执，每次运行最多一个回执。
- `audit_events` 记录登录、数据入库、运行、复核和报表分发动作。

# 002 档案取档表

同样由模型在启动时补建缺失表，不改动已有表结构。

- `archive_catalogs` 档案目录的不可变修订，以名称和 SHA-256 去重；同名新修订会令旧修订的 `superseded_at` 落值，旧修订随即失效。
- `procurement_plans` 取档方案：锁定目录修订的校验指纹与预算，保存各份复盘的原窗口参数、后台租约、计算结果与状态；目录换版或旧目录计算晚结束时置为 `stale`。
